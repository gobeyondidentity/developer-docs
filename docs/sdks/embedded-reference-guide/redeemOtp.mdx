The **redeemOtp** function enables an app using the Beyond Identity SDK to redeem an otp for a grant code. This function is used in conjunction with [authenticateOtp](embedded-reference-authenticateOtp).

## Dependencies

The **redeemOtp** function requires the Beyond Identity SDK.

<InstallationAll />

## Prerequisites

Before making a call to **redeemOtp**, you must complete the following prerequisite calls:

1. Import the required types and functions from the SDK.

  <ImportAll />

2. Initialize the SDK.

  <InitializeAll />

3. Use [authenticateOtp](embedded-reference-authenticateOtp) to initiate authentication using an OTP, and keep the **url** of the **OtpChallengeResponse** it returns.

4. Use **redeemOtp** to redeem the OTP the user received (see [example](#example-call-redeemotp) below).

## Returns

The **redeemOtp** function returns either an [AuthenticateResponse](embedded-reference-authenticate#returns) if the OTP was correct, or an **OtpChallengeResponse** if it was not:

<Tabs groupId="sdks" queryString>
<TabItem value="javascript" label="JavaScript">

The Promise resolves to an **AuthenticateResponse** on success, or an **OtpChallengeResponse** if the OTP was wrong.

</TabItem>
<TabItem value="kotlin" label="Kotlin">

```kotlin
sealed class RedeemOtpResponse {
    data class Success(val authenticateResponse: AuthenticateResponse) : RedeemOtpResponse()
    data class FailedOtp(val otpChallengeResponse: OtpChallengeResponse) : RedeemOtpResponse()
}
```

</TabItem>
<TabItem value="swift" label="Swift">

```swift
public enum RedeemOtpResponse: Equatable, Hashable {
    case success(AuthenticateResponse)
    case failedOtp(OtpChallengeResponse)
}
```

</TabItem>
<TabItem value="reactnative" label="React Native">

```javascript
redeemOtp(url: string, otp: string): Promise<AuthenticateResponse | OtpChallengeResponse>
```

Check for `redirectUrl` in the response to tell the two apart.

</TabItem>
<TabItem value="flutter" label="Flutter">

```dart
class RedeemOtpResponse {
  final AuthenticateResponse? success;
  final OtpChallengeResponse? failedOtp;
  bool get isSuccess;
  bool get isFailedOtp;
}
```

</TabItem>
</Tabs>

On Kotlin, the result is delivered to the callback, or emitted by the returned `Flow`. On Swift, it is delivered to the callback, or returned by the `async throws` variant. On JavaScript, React Native and Flutter, the function returns a Promise or `Future`.

On success, the **AuthenticateResponse** contains the following keys:

- **redirectUrl**: string containing the redirect URL that originates from the /authorize call's `redirect_uri` parameter. The OAuth2 authorization `code` and the `state` parameter of the /authorize call are attached with the "code" and "state" parameters to this URL.

- **message**: optional string containing a displayable message defined by policy returned by the cloud on success.

- **passkeyBindingToken**: string containing a one-time-token that may be redeemed for a CredentialBindingLink.

You can exchange the token for a link by calling the [credential-binding-jobs](https://developer.beyondidentity.com/api/v1#tag/Credential-Binding-Jobs) endpoint.

```javascript
const response = await fetch(
  `https://auth-${region}.beyondidentity.com/v1/tenants/${tenantId}/realms/${realmId}/applications/${applicationId}/credential-binding-jobs`,
  {
    method: "POST",
    headers: { Authorization: `Bearer ${passkeyBindingToken}` },
  }
);
```

This response will contain a `credential_binding_link`, which can be used by [isBindPasskeyUrl](embedded-reference-isBindPasskeyUrl) and [bindPasskey](embedded-reference-bindPasskey) to bind the credential.

If the OTP was wrong, the **OtpChallengeResponse** contains the following key:

- **url**: a URL containing the state of the authentication. Use it when calling **redeemOtp** or [authenticateOtp](embedded-reference-authenticateOtp) again.

## Examples

### Example: Call **redeemOtp**

<Tabs groupId="sdks" queryString>
<TabItem value="javascript" label="JavaScript">

```javascript
let response = await embedded.redeemOtp(url, otp);
```

</TabItem>
<TabItem value="kotlin" label="Kotlin">

```kotlin
import com.beyondidentity.embedded.sdk.EmbeddedSdk
import com.beyondidentity.embedded.sdk.models.RedeemOtpResponse

EmbeddedSdk.redeemOtp(url, otp) { result ->
    result.onSuccess { response ->
        when (response) {
            is RedeemOtpResponse.Success ->
                print("Authenticated. Redirect to ${response.authenticateResponse.redirectUrl}")
            is RedeemOtpResponse.FailedOtp ->
                print("Incorrect OTP. Retry with ${response.otpChallengeResponse.url}")
        }
    }
    result.onFailure { e ->
        print("Error redeeming OTP: $e")
    }
}
```

</TabItem>
<TabItem value="swift" label="Swift">

```swift
Embedded.shared.redeemOtp(url: url, otp: otp) { result in
    switch result {
    case .success(.success(let authenticateResponse)):
        print("Authenticated. Redirect to \(authenticateResponse.redirectUrl)")
    case .success(.failedOtp(let otpChallengeResponse)):
        print("Incorrect OTP. Retry with \(otpChallengeResponse.url)")
    case .failure(let error):
        print("Error redeeming OTP: \(error.localizedDescription)")
    }
}
```

</TabItem>
<TabItem value="reactnative" label="React Native">

```javascript
const response = await Embedded.redeemOtp(url, otp);
if ("redirectUrl" in response) {
  console.log("Authenticated. Redirect to", response.redirectUrl);
} else {
  console.log("Incorrect OTP. Retry with", response.url);
}
```

</TabItem>
<TabItem value="flutter" label="Flutter">

```dart
RedeemOtpResponse response = await EmbeddedSdk.redeemOtp(url, otp);
if (response.isSuccess) {
  print("Authenticated. Redirect to ${response.success!.redirectUrl}");
} else if (response.isFailedOtp) {
  print("Incorrect OTP. Retry with ${response.failedOtp!.url}");
}
```
