The **initialize** function sets up the Beyond Identity SDK and gives your app access to the rest of the SDK functions. The **initialize** function must be called first, before any other SDK functions.

## Dependencies

The **initialize** function requires the Beyond Identity SDK.

<InstallationAll />

## Prerequisites

Before making a call to **initialize**, you must import the SDK.

## Returns

<Tabs groupId="sdks" queryString>
<TabItem value="javascript" label="JavaScript">

On success, returns a Promise that resolves to an instance of the **Embedded** class. Call the other SDK functions on this instance.

</TabItem>
<TabItem value="kotlin" label="Kotlin">

`EmbeddedSdk` is a singleton `object`, so `init` returns nothing. Call the other SDK functions on `EmbeddedSdk` once it returns.

`init` throws a `DatabaseSetupException` if the SDK cannot set up its local database. The other functions report failure as a `Throwable` in their `Result`.

</TabItem>
<TabItem value="swift" label="Swift">

The callback receives `.success(())`, or `.failure(BISDKError)`. The `async throws` variant returns nothing and throws a `BISDKError` on failure. Once it succeeds, call the other SDK functions on `Embedded.shared`.

Every Swift SDK function reports failure as a `BISDKError`:

| Case | Meaning |
| --- | --- |
| `description(String)` | A failure described by the associated message. |
| `passkeyNotFound` | The passkey does not exist on this device. |
| `invalidUrlType` | The URL is not valid for this function. |
| `initializationIncomplete` | `Embedded.shared` was used before `Embedded.initialize` completed. |
| `outOfMemory` | There is not enough disk space to complete the operation. |
| `insufficientWritePermission(String)`, `insufficientReadPermission(String)` | The SDK cannot write to or read from the directory at the given path. |
| `unknownWritePermission(String)`, `unknownReadPermission(String)` | An unknown error occurred writing to or reading from the directory at the given path. |

</TabItem>
<TabItem value="reactnative" label="React Native">

On success, returns a Promise that resolves to the string `'success'`. Call the other SDK functions on `Embedded` once it resolves. On failure, the Promise rejects with an error.

</TabItem>
<TabItem value="flutter" label="Flutter">

Returns a `Future<void>` that completes once the SDK is initialized, and completes with an error if initialization fails. Call the other SDK functions on `EmbeddedSdk` once it completes.

</TabItem>
</Tabs>
