| Parameter | Type | Description |
| --- | --- | --- |
| **id** | `Passkey.Id` | Required. The ID of the passkey to be deleted. This should match the **id** property of a [Passkey](/docs/embedded-reference-passkey-type) that is available on the device. Passed with the argument label `for`. |
| **callback** | `@escaping (Result<Void, BISDKError>) -> Void` | Required. Called with the result of the deletion. |

The `async throws` variant takes the same parameters without **callback**, returns the result directly, and throws a `BISDKError` on failure.
