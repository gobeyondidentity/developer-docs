This page outlines the size of the Beyond Identity SDKs.

:::note
These are approximations as the size can vary based on architecture and device type.
:::

The numbers below are updated as of version 2.2.0 of the SDK.

| Platform | Download Size | Install Size |
| -------- | ------------- | ------------ |
| Kotlin   | 23.7 MB       | 41.6 MB      |
| Swift    | 20.7 MB       | 54.1 MB      |

The Flutter and React Native SDKs wrap the Kotlin and Swift SDKs, so their size on each platform is close to the numbers above.
