The SDK requires Flutter 3.44.0 or later.

### Pub.Dev

Add the Beyond Identity Embedded SDK to your dependencies

```gradle
dependencies:
  bi_sdk_flutter: x.y.z
```

and run an implicit `flutter pub get`.

### Update Android

Please make sure your `android/build.gradle` supports `minSdkVersion` 26 or later.

```gradle
buildscript {
  ext {
    minSdkVersion = 26
  }
}
```

For biometric prompts to work on Android, your Activity must extend `FragmentActivity`. Use `FlutterFragmentActivity` instead of `FlutterActivity`:

```kotlin title="android/app/src/main/kotlin/.../MainActivity.kt"
import io.flutter.embedding.android.FlutterFragmentActivity

class MainActivity : FlutterFragmentActivity()
```

### Update iOS

Please make sure your project supports "minimum deployment target" 15.1 or later.
In your `ios/Podfile` set:

```sh
platform :ios, '15.1'
```
